# Генератор чеков (HTML + PDF)

Программа берёт данные из CSV / XLS / XLSX, подставляет их в HTML-шаблон чека
и для каждой выбранной записи создаёт отдельный HTML- и PDF-файл.
Работает в терминале, на Windows и macOS.

---

## 1. Требования

- **Python 3.9 или новее** (проверено на Python 3.12). Скачать: <https://www.python.org/downloads/>
  При установке в Windows отметьте галочку **«Add Python to PATH»**.
- Библиотеки из `requirements.txt` (см. ниже).
- Для PDF — системная библиотека **Pango** (нужна WeasyPrint).

## 2. Установка

Откройте терминал в папке проекта (в Windows: в Проводнике откройте папку, в адресной строке
наберите `powershell` и нажмите Enter).

**Рекомендуется** виртуальное окружение — отдельная «коробка» для библиотек проекта:

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS
python3 -m venv .venv
source .venv/bin/activate
```

Установка библиотек:

```bash
pip install -r requirements.txt
```

### Зачем нужна каждая библиотека

| Библиотека   | Зачем                                                     |
|--------------|-----------------------------------------------------------|
| `weasyprint` | превращает HTML + CSS в PDF                               |
| `pandas`     | читает Excel-файлы и приводит их к единому виду           |
| `openpyxl`   | «движок» pandas для чтения `.xlsx`                        |
| `xlrd`       | «движок» pandas для чтения старых `.xls`                  |

CSV читается стандартным модулем `csv` — отдельная библиотека не нужна.

### Установка WeasyPrint

**macOS:**

```bash
brew install pango
pip install weasyprint
```

**Windows.** WeasyPrint нужна библиотека Pango, которой в Windows нет «из коробки»:

1. Установите MSYS2: <https://www.msys2.org/> (путь по умолчанию `C:\msys64`).
2. Откройте из меню «Пуск» программу **MSYS2 MINGW64** и выполните:
   ```
   pacman -S mingw-w64-x86_64-pango
   ```
3. Всё. Программа сама найдёт библиотеки в `C:\msys64\mingw64\bin`.
   Если MSYS2 установлен в другое место — укажите путь в `config.py`:
   ```python
   WEASYPRINT_DLL_DIR = r"D:\msys64\mingw64\bin"
   ```

Если WeasyPrint не установлен или не запускается, программа покажет инструкцию и предложит
создать **только HTML-файлы**. Подробнее: <https://doc.courtbouillon.org/weasyprint/stable/first_steps.html>

## 3. Структура проекта

```
PDFchek/
├── main.py              # запуск программы и пошаговый сценарий
├── config.py            # ВСЕ настройки (папки, шрифты, логотип, открытие PDF)
├── utils.py             # ввод в консоли, выбор из списка, логирование
├── file_manager.py      # поиск файлов, безопасные имена, открытие PDF
├── data_reader.py       # чтение CSV / XLS / XLSX
├── template_engine.py   # подстановка {{плейсхолдеров}}, логотип, общий CSS
├── pdf_generator.py     # создание HTML и PDF, подключение шрифтов
├── requirements.txt     # список библиотек
├── run_windows.bat      # запуск двойным щелчком в Windows
│
├── templates/           # HTML-шаблоны
│   ├── check_standard.html   # чек с таблицей товаров/услуг
│   ├── check_return.html     # чек возврата (логотип вставляется автоматически)
│   ├── check_services.html   # чек для таблицы «Клиент | услуга | стоимость | дата»
│   └── other/check_additional.html  # узкий чек 80 мм со всеми полями записи
├── data/                # файлы с данными
│   ├── clients.csv
│   ├── clients_2026.xlsx
│   └── archive/  (old_payments.xls, payments_1251.csv)
├── logos/               # логотипы
├── fonts/               # шрифты Roboto (для кириллицы в PDF)
│
└── output/              # создаётся автоматически
    ├── html/            # готовые HTML
    ├── pdf/             # готовые PDF
    └── logs/app.log     # журнал работы
```

Программа **только читает** шаблоны и файлы данных — они никогда не изменяются.
Всё созданное сохраняется только в `output/`.

## 4. Куда класть файлы

| Что                     | Куда по умолчанию                | Форматы                     |
|-------------------------|----------------------------------|-----------------------------|
| HTML-шаблоны            | `templates/`, `templates/other/` | `.html`, `.htm`             |
| Данные                  | `data/`, `data/archive/`         | `.csv`, `.xls`, `.xlsx`     |
| Логотипы                | `logos/`                         | `.png`, `.jpg`, `.jpeg`, `.svg` |
| Шрифты                  | `fonts/`                         | `.ttf`, `.otf`              |

Имена файлов могут быть любыми — программа сама найдёт все файлы и покажет список.

## 5. Запуск

```bash
python main.py
```

(в macOS — `python3 main.py`). В Windows можно просто дважды щёлкнуть `run_windows.bat`.

Режим с подробной технической информацией об ошибках:

```bash
python main.py --debug
```

В любой момент можно ввести `q` и нажать Enter, чтобы выйти.

## 6. Как пользоваться

```
Выберите шаблон

  [1] Чек возврат — check_return.html  (templates)
  [2] Чек стандартный — check_standard.html  (templates)
  [3] Чек дополнительный (узкий, 80 мм) — check_additional.html  (templates\other)

Ваш выбор: 2
```

1. **Шаблон.** Введите номер. Название берётся из тега `<title>` шаблона.
2. **Файл данных.** Введите номер. Если в Excel-файле несколько листов, программа спросит,
   какой лист взять. Если найден только один шаблон или один файл, он выбирается сам.
3. **Записи.** Программа покажет список (`Иванов Иван — № 1001`). Варианты ввода:
   - `5` — одна запись;
   - `5,8,12` — несколько записей;
   - `2-10` — диапазон;
   - `all` (или `все`) — все записи;
   - `Иванов` — **поиск**: покажет только записи, где встречается этот текст.
     Для поиска по числу поставьте в начале вопросительный знак: `?1001`.
4. **Логотип.** `[0]` — без логотипа, или номер файла.
5. **Проверка.** Программа покажет данные выбранных записей и итог:
   ```
   Шаблон: Чек стандартный (check_standard.html)
   Файл: clients.csv
   Записей: 3
   Логотип: company_logo.png
   Продолжить? [y/n]:
   ```
6. **Генерация.** Для каждой записи создаются `output/html/check_1001.html` и `output/pdf/check_1001.pdf`.

### Имена файлов

Имя строится из колонки с номером документа (`number`, `номер`, `№`, `id` — список в
`FILENAME_COLUMNS` в `config.py`): `check_1001.pdf`. Если такой колонки нет — по
порядковому номеру записи: `check_005.pdf`. Недопустимые символы (`/ \ : * ? " < > |`)
заменяются на `_`, поэтому номер `1004/А` превратится в `check_1004_А.pdf`.

Повторная генерация **перезаписывает** файлы с теми же именами.

### Открытие PDF после генерации

- Создан один PDF — он сразу открывается программой просмотра PDF.
- Создано несколько — программа спросит, что открыть; по Enter откроется **папка** с PDF
  (одно окно вместо десятков).

Отключить автооткрытие — в `config.py`:

```python
OPEN_AFTER_GENERATION = False
```

Поведение при нескольких PDF — `OPEN_MULTIPLE_MODE` (`"ask"`, `"folder"` или `"first"`).

## 7. Данные

Первая строка файла — **названия колонок**. Например:

```
number,date,name,address,service,quantity,price,amount,payment,comment
1001,30.09.2026,Иванов Иван,"г. Москва, ул. Ленина, д. 1",Консультация,1,5000,5000,Карта,Спасибо!
```

**CSV:**
- кодировка определяется автоматически: UTF-8, UTF-8 с BOM («CSV UTF-8» в Excel), Windows-1251;
- если определить не удалось, программа попросит ввести кодировку вручную (например, `cp866`).
  Можно задать её заранее: `CSV_ENCODING = "cp1251"` в `config.py`;
- разделитель (`,` `;` табуляция `|`) определяется автоматически (`CSV_DELIMITER` — вручную).

**XLS / XLSX:**
- даты выводятся как `30.09.2026` (или `30.09.2026 14:30`, если есть время);
- целые числа без `.0`: `5000`, а не `5000.0`;
- пустые ячейки становятся пустыми строками.

## 8. HTML-шаблоны

Плейсхолдер — это **название колонки в двойных фигурных скобках**: `{{name}}`, `{{amount}}`.
Регистр и пробелы внутри не важны (`{{ Name }}` = `{{name}}`), можно русские названия: `{{Клиент}}`.

```html
<h1>ЧЕК</h1>
<p>Клиент: {{name}}</p>
<p>Дата: {{date}}</p>
<p>Сумма: {{amount}} руб.</p>
```

Специальные плейсхолдеры (колонки для них не нужны):

| Плейсхолдер            | Что подставляется                             |
|------------------------|-----------------------------------------------|
| `{{logo}}`             | выбранный логотип                             |
| `{{all_fields_table}}` | таблица со всеми полями записи                |
| `{{today}}`            | сегодняшняя дата                              |
| `{{record_number}}`    | порядковый номер записи в файле               |

**Безопасность.** Все значения из данных экранируются (`html.escape`): символы `< > & " '`
выводятся как текст и не ломают разметку. Переносы строк внутри ячейки превращаются в `<br>`.

Если в данных нет колонки для какого-то плейсхолдера, программа предупредит и спросит,
продолжать ли; это место останется пустым (`MISSING_PLACEHOLDER_VALUE` в `config.py`).

> Внимание: плейсхолдеры заменяются **везде** в файле, в том числе внутри
> `<!-- комментариев -->` и CSS. Не пишите `{{...}}` там, где подстановка не нужна.

### Как добавить новый шаблон

1. Скопируйте любой шаблон из `templates/` и переименуйте, например `check_act.html`.
2. Поменяйте текст в `<title>` — это название, которое увидит пользователь в списке.
3. Расставьте плейсхолдеры с названиями колонок вашего файла данных.
4. Сохраните файл в кодировке **UTF-8**. Запустите программу — шаблон появится в списке.

Для каждого документа программа автоматически добавляет в начало `<head>` общий CSS:
шрифты, перенос длинных слов и аккуратное поведение таблиц. Стили самого шаблона идут
после него, поэтому их можно переопределить.

### Таблицы

Пример аккуратной таблицы (так сделано во встроенных шаблонах):

```css
table { width: 100%; border-collapse: collapse; }
th, td {
    border: 1px solid #999;
    padding: 6px 8px;
    text-align: left;
    vertical-align: top;
    word-wrap: break-word;
    overflow-wrap: break-word;
    word-break: break-word;
}
```

Длинные слова, ссылки и номера переносятся внутри ячейки и не выходят за край страницы.
Шапка таблицы (`<thead>`) повторяется на каждой новой странице PDF.

Размер страницы задаётся в шаблоне через `@page`, например `size: A4;` или
`size: 80mm 200mm;` для кассовой ленты (см. `templates/other/check_additional.html`).

## 9. Логотипы

- Положите файл в `logos/` — он появится в списке выбора.
- Лучше всего подходит **PNG** (с прозрачным фоном). JPG тоже работает.
- SVG поддерживается, но сложные SVG (фильтры, внешние шрифты) могут отображаться
  неточно. Если логотип выглядит неправильно — сохраните его в PNG.
- Если в шаблоне есть `{{logo}}`, логотип появится там. Если нет — в начале документа.
- Логотип встраивается прямо внутрь HTML, поэтому HTML-файл можно пересылать отдельно.

Размер (пропорции сохраняются всегда):

```python
LOGO_MAX_WIDTH = "180px"
LOGO_MAX_HEIGHT = "80px"
```

**Логотип по умолчанию для шаблона.** Чтобы при выборе шаблона сразу предлагался нужный
логотип (достаточно нажать Enter):

```python
TEMPLATE_LOGOS = {
    "check_return.html": "company_logo.png",
}
```

## 10. Шрифты (кириллица в PDF)

Чтобы русский текст в PDF выглядел одинаково на любом компьютере, программа подключает
шрифты **из файлов**, а не полагается на установленные в системе.

В папке `fonts/` уже лежат `Roboto-Regular.ttf`, `Roboto-Bold.ttf`, `Roboto-Italic.ttf`
(лицензия Apache 2.0). Можно добавить свои:

- **Roboto:** <https://fonts.google.com/specimen/Roboto> → Download → файлы `.ttf`;
- **Liberation Sans:** <https://github.com/liberationfonts/liberation-fonts/releases>
  (`LiberationSans-Regular.ttf`, `LiberationSans-Bold.ttf`).

Положите `.ttf` в `fonts/`. Семейство и начертание определяются по имени файла:
`Roboto-Bold.ttf` → Roboto, жирный; `LiberationSans-Italic.ttf` → Liberation Sans, курсив.

В CSS шаблона используйте:

```css
font-family: "Roboto", "Liberation Sans", sans-serif;
```

Другая папка шрифтов или отдельные файлы — в `config.py`:

```python
FONT_DIR = "fonts"
FONT_FILES = [r"C:\Fonts\Roboto-Regular.ttf"]
```

## 11. Как изменить папки поиска

Откройте `config.py` и допишите папки в списки. Пути считаются от папки проекта;
можно указывать и полные пути. Разделитель `/` работает и в Windows, и в macOS.

```python
TEMPLATE_DIRS = ["templates", "templates/other", r"D:\Шаблоны чеков"]
DATA_DIRS     = ["data", "data/archive", "/Users/anna/Documents/Выгрузки"]
LOGO_DIRS     = ["logos", "company"]
OUTPUT_DIR    = "output"
SEARCH_SUBFOLDERS = False   # True — искать и во вложенных папках
```

Если указанной папки нет, программа предупредит и продолжит искать в остальных.

## 12. Ошибки и журнал

Программа показывает понятные сообщения без технических подробностей. Подробный журнал
работы (какой шаблон, файл, записи, логотип выбраны, какие файлы созданы, какие ошибки
возникли) пишется в `output/logs/app.log`.

Частые ситуации:

| Сообщение                                        | Что сделать                                             |
|--------------------------------------------------|---------------------------------------------------------|
| «WeasyPrint не установлен»                       | `pip install weasyprint`                                |
| «не хватает системных библиотек»                 | установить Pango (раздел 2)                             |
| «Не удалось записать ...pdf: файл занят»         | закрыть этот PDF в программе просмотра                  |
| «Нет доступа к файлу ... закройте его в Excel»   | закрыть файл в Excel                                    |
| «Неправильная структура файла»                   | проверить разделитель и кавычки в указанной строке      |
| «Не удалось автоматически определить кодировку»  | ввести кодировку вручную или пересохранить CSV в UTF-8  |
| «шрифты Roboto / Liberation Sans не найдены»     | положить `.ttf` в `fonts/` (раздел 10)                  |

Для подробной технической информации: `python main.py --debug` или `DEBUG = True` в `config.py`.
